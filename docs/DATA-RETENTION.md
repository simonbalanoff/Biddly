# Data retention and deletion

Candidate records belong to the chapter workspace and should be retained only for a documented recruitment or compliance purpose. Chapter administrators can archive candidate records instead of keeping every record active indefinitely.

Candidate photos are private objects. The platform Storage page identifies orphaned objects and missing references. Safe cleanup only deletes objects that are not referenced by the database when deletion is requested.

A user can request account deletion from Settings. The account is deactivated and personally identifying account fields are replaced while audit integrity is preserved. A sole active chapter administrator must transfer administrator access before deletion.

Platform support notes should contain operational notes only. Do not place candidate information, passwords, private messages, or sensitive personal data in support notes.

Before launch, publish a customer-facing privacy policy and terms that accurately describe retention, subprocessors, support access, account deletion, and data export behavior.
